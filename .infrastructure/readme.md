# Legacy SaaS infrastructure

The Azure/Aspire deployment infrastructure in this directory belongs to the former SaaS product. It is not used to build or deploy the standalone Databricks App and must not be used for new VDAB installations.

Use the maintained [Databricks App documentation](../databricks-app/docs/README.md) for product setup and operation. This infrastructure is specific to the retired SaaS product and is not part of the VDAB App runtime.

# Current .NET HTTP API inventory

**Snapshot date:** 2026-10-16.  
**Purpose:** Step 1 trace from the existing SaaS API surface into the new HTTP contract. These are the legacy source routes, not the target Node route names. Route casing follows the C# attributes; Databricks HTTP paths are case-insensitive.

The source contains **201 `[Http*]` actions in 22 routed controller files** (23 controller files including `AuthenticatedControllerBase.cs`). This grouped list records every route attribute. `api/[controller]` has already been expanded to the controller name. Route constants in `AppActionsController` are resolved to their current values.
